O gerenciador de sessões SSH que guarda seus segredos no lugar certo.

Perfis, abas, painéis divididos, SFTP e sincronização de pastas em um app nativo e rápido, escrito em Rust. Senhas vão para o cofre do sistema, host keys são verificadas com rigor e não há telemetria.

Recursos

Perfis organizados

Pastas, tags, favoritos e ambientes DEV / HOMOLOGAÇÃO / PRODUÇÃO com faixa de aviso. Conexão rápida sem salvar nada.

Todas as formas de login

Senha, chave privada com ou sem passphrase, agente SSH e keyboard-interactive / MFA, inclusive por jump hosts.

Segredos no cofre do sistema

Keychain, Credential Manager ou Secret Service. Nada em texto puro no disco, em logs ou em argumentos de processo.

Host keys com rigor

Aceitar uma vez ou aceitar e salvar. Chave alterada bloqueia a conexão antes de qualquer envio.

Abas e painéis divididos

Terminal nativo (alacritty_terminal) com tema por perfil, seis paletas e confirmação de colagem com várias linhas.

Painel de arquivos SFTP

Local e remoto lado a lado, fila de transferências, tratamento de conflitos, cancelamento e retomada de arquivos grandes.

Sincronização com prévia

Sincronização unidirecional que mostra cada mudança antes de executar. Exclusões desligadas por padrão e modo espelho protegido.

Privado por padrão

Sem telemetria e sem verificação de atualização: a única rede usada é a das conexões que você inicia. Interface em inglês, português e espanhol.

Capturas de tela

As capturas usam dados fictícios de um servidor de teste local.

Compilar a partir do código

Requer Rust estável (edição 2024). No Debian/Ubuntu, instale antes as bibliotecas de janela e GPU com make deps-linux.

git clone https://github.com/xandroalmeida/mySSH.git
cd mySSH
cargo run -p myssh-app --release
