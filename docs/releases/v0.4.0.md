## mySSH v0.4.0 — 2026-11-19

### Destaques
- **Console local**: além das conexões SSH, o mySSH agora abre um terminal do próprio computador numa aba, ao lado das sessões remotas.
- O console local é um perfil como os outros: em **Novo perfil → Conexão → Console local**, escolha o shell e, se quiser, o diretório inicial; depois é só abrir pela lista de conexões.
- **Ctrl+Tab** alterna entre as abas, em qualquer sistema, mesmo com o terminal em foco.

### Novidades
- Console local com escolha do shell: no Linux e no macOS, os shells instalados no sistema; no Windows, cmd e PowerShell, quando disponíveis.
- Perfis de console local salvos na lista de conexões, com diretório inicial opcional (sem diretório, o console abre na pasta pessoal).
- Um perfil de console local não usa host, usuário, credenciais, jump host nem encaminhamento de agente; o formulário valida o shell e exige um caminho absoluto para o diretório inicial.
- Ctrl+Tab avança pelas abas em círculo.

### Correções
- Linux: a lista de shells do console local não mostra mais entradas que não são shells utilizáveis (como `false` e `nologin`), e o shell aberto recebe a variável `SHELL` correta.
- Os ícones de status do console local não aparecem mais como quadrados vazios quando a fonte do terminal não tem esses símbolos.

### Limitações conhecidas
- Windows: o console local (cmd/PowerShell) e as conexões SSH reais ainda não foram validados no Windows; o agente SSH do sistema ainda não é suportado lá.
- Os pacotes não são assinados nem notarizados. No Windows, o SmartScreen avisa na primeira execução; no macOS, o Gatekeeper pede confirmação.
- Dependência com alerta de segurança conhecido para chaves RSA (RUSTSEC-2023-0071): prefira chaves ed25519.

### Instalação (Linux)
Baixe o AppImage anexado, marque-o como executável (`chmod +x`) e abra, ou instale o `.deb` (`sudo apt install ./myssh_0.4.0_amd64.deb`). Também dá para usar `make install-linux`.

### Instalação (macOS)
`make install-mac`, ou abra o .dmg anexado quando estiver disponível. O app não é assinado: na primeira abertura, clique com o botão direito e escolha Abrir.

### Instalação (Windows)
Baixe o instalador `.exe` anexado, quando estiver disponível, e execute. Como ele não é assinado, o SmartScreen mostra "O Windows protegeu o computador": clique em "Mais informações" e depois em "Executar assim mesmo".
